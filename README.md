# Lozikheyi Estate — VanillaWebz Concept

An independent, non-commercial website concept prepared to demonstrate an interactive residential-development experience.

## Current experience
- Premium responsive landing page and house collection
- Clickable illustrative SVG masterplan with plot filtering, selection and zoom
- Four separate house-type pages
- Interactive Three.js house viewers with orbit rotation and zoom
- Type A conceptual two-bedroom floor-plan diagram
- Visual inspiration gallery
- Contact call-to-action placeholders

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Validate
```bash
npm run lint
npm run build
```

## Important concept limitations
This repository is a demonstration only. Plot locations, plot sizes, availability statuses, house areas, room arrangements, imagery and architectural models are illustrative and have not been approved or verified by the estate. The models and diagrams are not construction drawings. Replace all placeholders with the estate's official information and approved architectural/site material before any production use.

## Deployment
Deployment is intentionally deferred until the concept has been tested, reviewed and approved for presentation.
